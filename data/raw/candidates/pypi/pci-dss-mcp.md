## Configuration

Add to your `claude_desktop_config.json` (Claude Desktop) or your MCP client config:

```json
{
  "mcpServers": {
    "pci-dss-mcp": {
      "command": "uvx",
      "args": ["pci-dss-mcp"]
    }
  }
}
```

Or: `pip install pci-dss-mcp` then run the `pci-dss-mcp` command (stdio transport).
